# Todo App (Next.js Migration)

This branch contains the Next.js migration of the Todo App originally built in React.  
It uses the [Next.js App Router](https://nextjs.org/docs/app) with full CRUD functionality:

- View Todos  
- Create Todo  
- Update Todo  
- Delete Todo  
- Search, filter, and pagination (on homepage)  

---

## Tech Stack
- [Next.js 15](https://nextjs.org/) (App Router + TypeScript)
- React 18
- CSS
- Fetch API (for CRUD calls)
